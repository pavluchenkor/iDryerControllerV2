- **Рефакторинг источника данных дисплея — КОД ГОТОВ, ждёт проверки на железе.**
  `service_screen` теперь читает `controllers[u]->getInputs()` (снимок из `inputs_`) вместо своего `readDryerInputs()` — убирает дублирующий `report_sensor_error` (спам событий при обрыве вдвое меньше). `readDryerInputs` вызывается строго раз за цикл (main loop). Проверить сборкой RP: дисплей показывает те же данные, спам при обрыве уполовинен. Не закоммичено.

- **Автопроверка отпечатка wire-структур (когда `uart_protocol_version` уйдёт в прод).**
  Механизм версионирования проверен: `uart_protocol_version` (=2, пишется в каждый UART-фрейм, `header.version` проверяется при приёме) + `validateLength` (точный `sizeof` каждого payload — ловит рассинхрон размера в runtime, безопасный отказ, не мусор). Конвенция: изменил размер/поля payload → подними `uart_protocol_version` (коммент mqtt_contract.yaml:217; история char[8]→char[16] = bump до v2).
  Сейчас v2 НЕ опубликована → формат меняем свободно, bump не нужен, автопроверка пока только мешала бы.
  Когда v2 опубликуют — добавить в `contracts/validate_contract.py` проверку отпечатка: regen хранит эталон wire-формата (размеры всех payload-структур или один хеш) и **падает**, если формат изменился, а `uart_protocol_version` не поднят. Превращает «не забудь bump» из комментария-надежды в автоматический стоп, независимо от того, где правишь структуру. Комментарий-памятку в yaml не делать — слабый механизм (легко пропустить, дублируется по секциям).
