# Подключение весового датчика HX711

## Подключение через RJ45

Используется понижающий преобразователь напряжения.
На порту 5V (2(O)-VCC, 8(Br) - GND), питание HX711 — 3.3V

| Контакт | Назначение |
|---------|-----------|
| 1(WO)  | не используется |
| 2(O)   | VCC (5V) |
| 3(WG)  | SCALE_S0 |
| 4(B)   | SCALE_S1 |
| 5(WB)  | SCALE_SCK |
| 6(G)   | SCALE_DT |
| 7(WBr) | не используется |
| 8(Br)  | GND |

## Подключение к контроллеру

- SCALE_DT   → H2
- SCALE_SCK  → FAN2
- SCALE_S0   → SRV2
- SCALE_S1   → T2

## Схема RJ45

```
| DT | SCK | S0 | S1 | VCC | GND |
  |     |     |    |    |     |   
 (G)  (WB)  (WG)  (B)  (O)   (Br)
```
