# iDryerControllerV2

Основной контроллер сушилки iDryer. Управляет нагревом, вентилятором, весами и RFID-ридером.

## Что здесь

В этой документации описаны:

- **Установка и конфигурация** — прошивка контроллера через WebUSB и настройка портов
- **Подключение оборудования** — схемы подключения экрана, датчиков, модулей
- **Работа и управление** — описание меню контроллера и режимов работы
- **Протокол и API** — техническое описание UART/TLV протокола и Web API
- **FAQ** — ответы на частые вопросы про iDryer и iHeater
- **Тестирование** — процедуры испытаний основных режимов
