# iDryerControllerV2

![MCU PCB](../img/MCU_PCB.png)

Эта документация описывает прошивку, подключение и настройку платы управления iDryer.

Проект открыт для энтузиастов: прошивку можно запускать на микроконтроллерах RP2040, а при подключении нужной периферии контроллер будет полностью функционален.

## Основной функционал прошивки

Управляет нагревом, вентилятором и сервомашинкой, считывает показания температуры, влажности, весов и RFID-ридера.
С использованием ESP32 в качестве доступного Wi-Fi модуля (iDryer-Link) функционал контроллера расширяется телеметрией и беспроводным управлением. Управление может работать локально из приложения, а при подключении к порталу устройство отправляет телеметрию, получает команды, ведет историю данных. Эти данные особенно полезны для анализа процесса сушки и оценки состояния филамента.

## Быстрый старт

Начните с общего знакомства с документацией и двигайтесь по меню сверху вниз. Сначала подготовьте оборудование и проверьте, что у вас есть все необходимые модули, кабели и питание. Затем выполните первоначальную прошивку контроллера, настройте порты под вашу конфигурацию и подключите оборудование.

Основной путь работы сейчас строится вокруг портала: прошейте контроллер, затем подключите и прошейте iDryer-Link, после чего выполните подключение к Wi-Fi, Claim и привязку устройства к порталу. После этого сушилкой можно пользоваться через портал или приложение, а экран остается удобным сервисным способом управления и настройки, если вы хотите работать с устройством локально.
