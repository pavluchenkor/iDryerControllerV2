# 快速上手

从打印零件到烘干机可用的简短流程：打印外壳、连接模块、刷写固件、在门户完成绑定
（claim）以及风门的初次设置。每一步的详细说明请见文档中对应的章节。

## 需要准备

- 控制器主板（RP2040）和 **iDryer-Link** 模块（ESP32-C3 Super Mini）。
- 一根数据 USB 线。
- 支持 WebUSB 的 Chromium 浏览器（Chrome、Edge）。
- 带密码的 2.4 GHz Wi-Fi 网络。
- 门户账号 —— <https://portal.idryer.org>。

## 1. 接线

!!! warning "先在桌面上测试组装"
    在最终组装之前，先把所有部件在桌面上组装起来，确认设备能正常工作。趁还能接触
    到每个部件时，接线错误更容易排查。

!!! danger "电源"
    切勿在通电状态下连接或断开模块（Link、屏幕、传感器）。所有接线都必须在断电状态
    下进行。

请按照文档中对应的章节连接各模块和部件。刷写固件之前，Link 必须已连接到控制器。

!!! warning "不要接错线"
    接线看似简单，但接到主板的线常常被接错。这类错误很难远程诊断：烘干机表面上运行
    正常，但控制逻辑已经改变。例如，如果把风扇和加热器接反，设备看似能工作，但 PID
    控制器无法控制加热器 —— 加热器会一直满功率运行。

## 2. 刷写控制器和 Link

固件通过浏览器在 <https://install.idryer.org> 刷写。请按顺序完成向导的各步骤：

1. **Flash Controller** —— 将 USB 连接到控制器接口，将主板置于 `BOOTSEL` 模式，
   然后刷写控制器。
2. **Flash Link** —— 将 USB 线改插到 Link 接口（Link 仍与控制器保持连接），然后
   刷写该模块。

## 3. Wi-Fi 与门户绑定

在同一向导中继续，网址 <https://install.idryer.org>：

1. **Wi-Fi** —— 刷写 Link 之后会打开网络配置向导（Improv）。输入你的 Wi-Fi 网络
   名称（SSID）和密码。
2. **Claim** —— 启动绑定。向导会显示一个 `PIN`。
3. **门户** —— 打开 <https://portal.idryer.org>，登录，在设备页面添加设备并输入
   `PIN`。

绑定完成后，设备会出现在门户的列表中。

## 4. 打印外壳零件

请使用文档 CAD 章节中给出的参数打印外壳零件。这些参数已在数千台装机中得到验证。若
偏离这些参数，外壳会失去保温性能，烘干机也无法达到工作温度。

## 5. 风门与舵机

风门可以从控制器屏幕（菜单 `SETTINGS → SERVO`）、门户中的设备设置，或应用中进行
设置。

!!! warning "风门安装顺序"
    先设置角度，再安装风门 —— 否则风门会顶到外壳并使舵机堵转。

1. 设置 `CLOSED ANGLE = 0`。舵机会转到该位置（预览）。
2. 根据舵机轴的实际位置安装风门，使其在关闭位置能完全封住<!-- TODO: 确认术语 ——
   风门组件的开口/通道 -->风门组件的气道。
3. 根据你的机械结构设置 `OPEN ANGLE`。此步骤也可以在最终组装之后进行。

## 6. 加热 PID 控制器

固件已内置可用的 PID 控制器参数 —— 启动和初次检查无需单独校准。如有需要，可运行
autotune（自动整定），使参数适配你的装机。

## 7. 通过门户和应用控制

控制器的所有功能和菜单都可以通过门户和应用使用。门户和应用大幅扩展了烘干机的能力：
遥测、数据历史、预设以及远程控制。

可以从门户 <https://portal.idryer.org> 或应用进行控制：

- **Google Play** —— <https://play.google.com/store/apps/details?id=org.idryer.mobile>
- **App Store** —— <https://apps.apple.com/app/idryer/id6760609044>

开始烘干：

1. 打开门户或应用 —— 屏幕上会显示你设备的卡片。
2. 选择模式 —— 烘干或存储。
3. 按下开始。

默认的温度和时间数值适用于大多数情况。如有需要，可根据你的材料进行修改。

### 耗材记录与评价

货架上的每一卷耗材都会在门户中呈现，所有数据都会被记录。你可以为每种耗材撰写评价，
也可以阅读其他用户的评价。评价按厂商、类型等属性分组，可直接在门户和论坛中查看。
