# クイックスタート

部品の印刷から乾燥機が動作するまでの短い手順です。ケースの印刷、モジュールの配線、
書き込み、ポータルでの登録（claim）、ダンパーの初期設定を行います。各ステップの
詳細は、ドキュメントの該当セクションを参照してください。

## 必要なもの

- コントローラー基板（RP2040）と **iDryer-Link** モジュール（ESP32-C3 Super Mini）。
- データ用 USB ケーブル。
- WebUSB に対応した Chromium 系ブラウザ（Chrome、Edge）。
- パスワード付きの 2.4 GHz Wi-Fi ネットワーク。
- ポータルのアカウント — <https://portal.idryer.org>。

## 1. 配線

!!! warning "まず机上で組み立てて確認する"
    最終組み立ての前に、すべての部品を机の上で組み合わせ、機器が動作することを確認
    してください。すべての部品にアクセスできるうちの方が、配線ミスを見つけやすく
    なります。

!!! danger "電源"
    通電した状態でモジュール（Link、画面、センサー）を接続・取り外ししないで
    ください。配線はすべて電源を切った状態で行ってください。

ドキュメントの該当セクションに従ってモジュールと部品を配線してください。書き込みの
前に、Link はコントローラーに接続されている必要があります。

!!! warning "配線を取り違えない"
    配線は単純に見えますが、基板への配線はしばしば取り違えられます。この種のミスは
    遠隔での診断が難しく、乾燥機は一見正常に動作しているように見えても、制御ロジック
    が変わってしまいます。たとえばファンとヒーターを取り違えると、機器は動作している
    ように見えても、PID 制御がヒーターを制御できず、ヒーターが常にフルパワーで動作
    します。

## 2. コントローラーと Link の書き込み

書き込みはブラウザから <https://install.idryer.org> で行います。ウィザードの
手順を順番に進めてください。

1. **Flash Controller** — USB をコントローラーのポートに接続し、基板を `BOOTSEL`
   モードにして、コントローラーを書き込みます。
2. **Flash Link** — USB ケーブルを Link のポートに差し替え（Link はコントローラー
   に接続したまま）、モジュールを書き込みます。

## 3. Wi-Fi とポータルへの登録

同じウィザードのまま <https://install.idryer.org> で続けます。

1. **Wi-Fi** — Link の書き込み後、ネットワーク設定ウィザード（Improv）が開きます。
   Wi-Fi ネットワーク名（SSID）とパスワードを入力します。
2. **Claim** — 登録を開始します。ウィザードに `PIN` が表示されます。
3. **ポータル** — <https://portal.idryer.org> を開いてサインインし、デバイス
   ページでデバイスを追加して `PIN` を入力します。

登録すると、デバイスがポータルの一覧に表示されます。

## 4. ケース部品の印刷

ケース部品は、ドキュメントの CAD セクションで指定されたパラメーターで印刷して
ください。これらのパラメーターは数千台の組み立てで実証されています。これらから
外れると、ケースの断熱性が失われ、乾燥機が動作温度に達しません。

## 5. ダンパーとサーボ

ダンパーは、コントローラーの画面（メニュー `SETTINGS → SERVO`）、ポータルの
デバイス設定、またはアプリから設定できます。

!!! warning "ダンパーの取り付け順序"
    先に角度を設定してからダンパーを取り付けてください。そうしないと、ダンパーが
    ケースに当たってサーボが動かなくなります。

1. `CLOSED ANGLE = 0` を設定します。サーボがこの位置に動きます（プレビュー）。
2. シャフトの実際の位置に合わせてダンパーを取り付け、閉位置でダンパーが<!-- TODO:
   用語を確認 — ダンパーユニットの開口/通路 -->ダンパーユニットの空気通路を完全に
   ふさぐようにします。
3. 機構に合わせて `OPEN ANGLE` を設定します。この手順は最終組み立ての後に行う
   こともできます。

## 6. ヒーターの PID 制御

ファームウェアには動作する PID 制御の値があらかじめ入っており、起動と初期確認の
ために別途の校正は必要ありません。必要に応じて autotune（オートチューン）を実行し、
係数を組み立てに合わせて調整してください。

## 7. ポータルとアプリからの操作

コントローラーのすべての機能とメニューは、ポータルとアプリから利用できます。ポータル
とアプリは、乾燥機の機能を大幅に拡張します。テレメトリ、データ履歴、プリセット、
遠隔操作などです。

操作はポータル <https://portal.idryer.org> またはアプリから行えます。

- **Google Play** — <https://play.google.com/store/apps/details?id=org.idryer.mobile>
- **App Store** — <https://apps.apple.com/app/idryer/id6760609044>

乾燥を開始するには:

1. ポータルまたはアプリを開くと、画面にデバイスのカードが表示されます。
2. モードを選択します — 乾燥または保管。
3. スタートを押します。

デフォルトの温度と時間の値は、ほとんどの場合に適した値になっています。必要に応じて
使用する材料に合わせて変更してください。

### フィラメントの記録とレビュー

棚にあるフィラメントはすべてポータルに反映され、すべてのデータが記録されます。
各フィラメントについてレビューを投稿したり、他のユーザーのレビューを読んだりでき
ます。レビューはメーカー、種類などの属性ごとにまとめられ、ポータルとフォーラムから
直接利用できます。
