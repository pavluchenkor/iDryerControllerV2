# iDryerControllerV2

Main dryer controller for iDryer. Controls heater, fan, scales, and RFID reader.

## What's here

This documentation covers:

- **Installation and configuration** — flashing the controller via WebUSB and port setup
- **Hardware connections** — wiring diagrams for screen, sensors, and modules
- **Operation and control** — controller menu description and operation modes
- **Protocol and API** — technical description of UART/TLV protocol and Web API
- **FAQ** — answers to frequent questions about iDryer and iHeater
- **Testing** — test procedures for basic operation modes

## Quick start

1. [Flash the controller](installation/firmware-install.md)
2. [Configure ports](installation/port-config.md) for your setup
3. [Connect hardware](hardware/) according to diagrams
4. [Learn the menu](operation/menu-manual.md)
