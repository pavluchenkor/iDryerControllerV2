# 快速上手

從列印零件到烘乾機可用的簡短流程：列印外殼、連接模組、燒錄韌體、在入口網站完成綁定
（claim）以及風門的初次設定。每個步驟的詳細說明請見文件中對應的章節。

## 需要準備

- 控制器主機板（RP2040）和 **iDryer-Link** 模組（ESP32-C3 Super Mini）。
- 一條資料 USB 線。
- 支援 WebUSB 的 Chromium 瀏覽器（Chrome、Edge）。
- 帶密碼的 2.4 GHz Wi-Fi 網路。
- 入口網站帳號 —— <https://portal.idryer.org>。

## 1. 接線

!!! warning "先在桌面上測試組裝"
    在最終組裝之前，先把所有部件在桌面上組裝起來，確認裝置能正常運作。趁還能接觸到
    每個部件時，接線錯誤更容易排查。

!!! danger "電源"
    切勿在通電狀態下連接或拔除模組（Link、螢幕、感測器）。所有接線都必須在斷電狀態下
    進行。

請依照文件中對應的章節連接各模組和部件。燒錄韌體之前，Link 必須已連接到控制器。

!!! warning "不要接錯線"
    接線看似簡單，但接到主機板的線常常被接錯。這類錯誤很難遠端診斷：烘乾機表面上運作
    正常，但控制邏輯已經改變。例如，若把風扇和加熱器接反，裝置看似能運作，但 PID
    控制器無法控制加熱器 —— 加熱器會一直滿功率運轉。

## 2. 燒錄控制器和 Link

韌體透過瀏覽器在 <https://install.idryer.org> 燒錄。請依序完成精靈的各步驟：

1. **Flash Controller** —— 將 USB 連接到控制器連接埠，將主機板置於 `BOOTSEL`
   模式，然後燒錄控制器。
2. **Flash Link** —— 將 USB 線改插到 Link 連接埠（Link 仍與控制器保持連接），然後
   燒錄該模組。

## 3. Wi-Fi 與入口網站綁定

在同一精靈中繼續，網址 <https://install.idryer.org>：

1. **Wi-Fi** —— 燒錄 Link 之後會開啟網路設定精靈（Improv）。輸入你的 Wi-Fi 網路
   名稱（SSID）和密碼。
2. **Claim** —— 啟動綁定。精靈會顯示一組 `PIN`。
3. **入口網站** —— 開啟 <https://portal.idryer.org>，登入，在裝置頁面新增裝置並
   輸入 `PIN`。

綁定完成後，裝置會出現在入口網站的清單中。

## 4. 列印外殼零件

請使用文件 CAD 章節中提供的參數列印外殼零件。這些參數已在數千台組裝中獲得驗證。若
偏離這些參數，外殼會失去保溫效果，烘乾機也無法達到工作溫度。

## 5. 風門與伺服機

風門可以從控制器螢幕（選單 `SETTINGS → SERVO`）、入口網站中的裝置設定，或應用程式
中進行設定。

!!! warning "風門安裝順序"
    先設定角度，再安裝風門 —— 否則風門會頂到外殼並使伺服機堵轉。

1. 設定 `CLOSED ANGLE = 0`。伺服機會轉到該位置（預覽）。
2. 依照伺服機軸的實際位置安裝風門，使其在關閉位置能完全封住<!-- TODO: 確認術語 ——
   風門組件的開口/通道 -->風門組件的氣道。
3. 依照你的機械結構設定 `OPEN ANGLE`。此步驟也可以在最終組裝之後進行。

## 6. 加熱 PID 控制器

韌體已內建可用的 PID 控制器參數 —— 啟動和初次檢查無需另行校正。如有需要，可執行
autotune（自動整定），使參數適配你的組裝。

## 7. 透過入口網站和應用程式控制

控制器的所有功能和選單都可以透過入口網站和應用程式使用。入口網站和應用程式大幅擴充
了烘乾機的能力：遙測、資料歷史、預設以及遠端控制。

可以從入口網站 <https://portal.idryer.org> 或應用程式進行控制：

- **Google Play** —— <https://play.google.com/store/apps/details?id=org.idryer.mobile>
- **App Store** —— <https://apps.apple.com/app/idryer/id6760609044>

開始烘乾：

1. 開啟入口網站或應用程式 —— 螢幕上會顯示你裝置的卡片。
2. 選擇模式 —— 烘乾或存放。
3. 按下開始。

預設的溫度和時間數值適用於大多數情況。如有需要，可依你的材料進行修改。

### 耗材記錄與評價

貨架上的每一捲耗材都會在入口網站中呈現，所有資料都會被記錄。你可以為每種耗材撰寫
評價，也可以閱讀其他使用者的評價。評價依廠商、類型等屬性分組，可直接在入口網站和
論壇中查看。
