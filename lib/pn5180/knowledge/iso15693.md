# ISO/IEC 15693 (VICC) — конспект для PN5180

Применяется в iDryer для ICODE SLIX2 / ISO15693-generic меток. PN5180 работает
как VCD (Vicinity Coupling Device).

## Формат кадра

```
SOF  Flags(1B)  Command(1B)  [UID(8B)]  [Params...]  CRC16(2B)  EOF
```

Флаги чаще всего: `0x22` (1/4 coding, high data rate, без inventory) или
`0x26` (+ select flag = 1 для адресного режима). Для адресного кадра
добавляются 8 байт UID сразу после команды.

`ISO15693_FLAG_DATA_RATE_HIGH = 0x02`, `ISO15693_FLAG_ADDRESS = 0x20`.

## Часто используемые команды

| Код  | Имя                | Параметры (после флагов)                  | Ответ                       |
|------|--------------------|-------------------------------------------|-----------------------------|
| 0x01 | Inventory          | AFI (опц.), mask length, mask             | DSFID + UID(8B)             |
| 0x02 | Stay Quiet         | —                                         | нет                         |
| 0x20 | Read Single Block  | block (1B)                                | Flags + block data + CRC    |
| 0x21 | Write Single Block | block (1B) + data                         | Flags (+ error code)        |
| 0x22 | Lock Block         | block                                     | Flags                       |
| 0x23 | Read Multiple Blocks | first (1B) + count-1 (1B)              | Flags + N × block data      |
| 0x24 | Write Multiple Blocks | first + count-1 + data                 | Flags                       |
| 0x25 | Select             | UID                                       | Flags                       |
| 0x26 | Reset to Ready     | —                                         | Flags                       |
| 0x2B | Get System Info    | —                                         | InfoFlags, UID, DSFID, AFI, VICC memory size, IC ref |
| 0x2C | Get Multiple Block Security Status | first + count-1            | Flags + N × 1 B             |

## Ответ и статус

Первый байт ответа VICC — **Response Flags**:
- бит 0 = Error flag (0 = OK, 1 = error, следом 1 байт Error code)
- бит 1 = Extension flag
- биты 2..7 = RFU

Коды ошибок (примеры): `0x01` — command not supported, `0x02` — command not
recognized, `0x03` — option not supported, `0x0F` — unknown error, `0x10` —
block not available, `0x11` — block already locked, `0x12` — block locked и
не может быть записан, `0x13` — block write error, `0x14` — block locked.

## Размеры блоков

| Метка         | blockSize | totalBlocks | userBlocks |
|---------------|-----------|-------------|-----------|
| ICODE SLIX    | 4         | 28          | 0..27     |
| ICODE SLIX2   | 4         | 79          | 0..79     |
| ICODE SLIX-S  | 4         | 40          | 0..39     |
| Tag-it HF-I Plus | 4      | 64          | 0..63     |

Фактические значения надо брать из `GetSystemInfo` (infoFlags bit 2 → блоки
присутствуют), не полагаться на геометрию по умолчанию.

## Тайминги записи

- `t_write` WriteSingleBlock (ICODE SLIX2): тип. 4 мс, макс. 8 мс.
- После WriteSingleBlock метка может держать поле занятым — минимальный межкадровый интервал 1 мс.
- Inventory требует `fieldOn` минимум за ~5 мс до команды для ICODE.

## CRC

CRC_A 16 бит, полином 0x8408, initial 0xFFFF, результат инвертируется.
PN5180 считает CRC автоматически, если `CRC_TX=on`, `CRC_RX=on`. Для ISO15693
оба всегда включены.

## Sequence чтения пользовательской области

```
Inventory (1-слот, flags=0x26, mask=0) → UID
GetSystemInfo(uid) → blockSize, totalBlocks
ReadMultipleBlocks(uid, first=0, count=N)   // чанками ≤ 32 блока
```
