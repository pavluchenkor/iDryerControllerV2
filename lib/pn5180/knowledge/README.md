# lib/pn5180/knowledge

Локальная база знаний для драйвера PN5180. Сюда складываем выжимки из
спецификаций, чтобы не ходить в интернет при каждой правке.

## Содержимое

- [pn5180_chip.md](pn5180_chip.md) — выжимка по самому PN5180 (регистры, IRQ, transceive state machine, нюансы работы с partial-byte responses).
- [ntag21x.md](ntag21x.md) — NTAG213/215/216: команды, ACK/NAK, тайминги, карта памяти.
- [iso15693.md](iso15693.md) — ISO/IEC 15693 (ICODE SLIX2 и др.): формат кадра, команды, блоки, тайминги.
- `../pn5180.txt` — полный официальный datasheet PN5180 (Rev. 4.3, 2025-10-30), для справки.

## Правила ведения

1. Все факты помечать источником: `[ds]` datasheet, `[appnote]` application note,
   `[empirical]` — проверено на стенде, `[forum]` — подтверждено сообществом.
2. Не хранить сюда full-text PDF — только выжимки. Сами PDF лежат рядом
   (`pn5180.txt`) или ссылками.
3. При каждом найденном «подводном камне» в драйвере — фиксировать здесь,
   чтобы следующий раз не наступать.
