# iDryer Standalone Firmware: why use it if Klipper already exists

The existing Klipper integration covers most core filament drying and storage needs. It is a familiar and convenient option for users already working inside a printer-first ecosystem.

At the same time, iDryer Standalone firmware offers a more flexible and feature-rich workflow as an independent drying control platform.

## What standalone firmware adds

- A broader set of modes and settings for different real-world use cases.
- Extended scales support and material usage tracking directly on the iDryer side.
- Portal integration: [portal.iDryer.org](https://portal.idryer.org).
- A unified approach to multi-module management and configuration.

## One hardware platform

This is a logical transition from two different platforms to one unified hardware platform.

Today, both iDryer X and iDryer Unit use the same hardware and the same controller. This provides clear advantages:

- one universal firmware instead of parallel maintenance of separate branches;
- one portal and a more consistent user experience;
- faster product evolution, because development is focused on one firmware and one backend direction.

## Standalone modularity

Standalone firmware is designed around a modular architecture from the start. Depending on the stand configuration, it can support:

- RFID(soon);
- scales;
- display;
- touchscreen and portal integration.

Module capabilities will continue to expand in upcoming firmware and ecosystem releases.
