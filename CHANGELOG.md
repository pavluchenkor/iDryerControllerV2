# Changelog

Этот файл ведется на русском языке и фиксирует заметные изменения в прошивке iDryer RP2040.

История до появления этого файла восстановлена по `git log`. Для ранних этапов, где в репозитории не было оформленных релизов, изменения сгруппированы по периодам разработки, а не по строгим версиям.

## [1.0.3] - 2026-04-04

Статус: предрелизная сборка.

### Исправлено

- Исправлено несколько ошибок в каскадном PID-регуляторе: антивинтап, диапазон выхода нагревательного контура, параметры при обновлении коэффициентов из меню.
- Исправлен таймер и логика состояния заслонки: отсчёт времени и флаг `open/closed` теперь определяются по фактическому положению серво, а не по команде.
- Исправлена инициализация интервала обновления PID.

### Добавлено

- Изменение GAIN из меню применяется без сброса интеграла PID.
- В лог оперативного контроля добавлены P/I/D/Gm для обоих контуров каскада.

## [1.0.2] - 2026-04-03

Статус: предрелизная сборка.

### Изменено

- Изменен вывод отладочной информации: вместо `idle` используется `!idle`.
- Удалено двойное накопление интегральной составляющей регулятора.

## [Предрелиз 1.0.x] - 2026-03-13..2026-03-27

### Добавлено

- Улучшено автоопределение cradle на `Port0` по UART.
- Добавлена минимальная задержка приветственного экрана 3 секунды.
- В ответ `UartHello` добавлена передача `sendWsEnable`.
- В post-build скрипт добавлено автокопирование прошивки для flasher/portal.
- Добавлена документация по окружению разработки и build-скриптам.

### Исправлено

- Устранена race condition в автоопределении UART.

### Изменено

- Обновлена логика работы LED-индикации.
- Обновлен submodule `idryer-protocol`.

## [Январь-Февраль 2026] - 2026-01-09..2026-02-09

### Добавлено

- Подключен `idryer-protocol` как git submodule.
- Реализован UART с выбором активного юнита.
- В меню добавлен hook на изменение конфигурации.
- Размер EEPROM увеличен до 4096 байт.
- Реализован overlay-экран ошибок.

### Исправлено

- Исправлена работа UART после регрессий и обновления submodule.
- Исправлена проблема `Serial1` в UART-подсистеме.
- Обновлен submodule для исправления CRC.
- Исправлена логика тары для датчика HX711.
- Добавлены попытки восстановления после нестабильных состояний.

### Изменено

- Проведена глобальная реструктуризация кода.

## [Октябрь-Декабрь 2025] - 2025-10-01..2025-12-23

### Добавлено

- Реализована подсистема ошибок.
- Добавлено управление сервоприводом по RH.
- Добавлена поддержка весов.
- Добавлен новый алгоритм `VH` и управление `VH`.

### Исправлено

- Исправлены проблемы достижения PID-цели.
- Исправлена проверка нагревателя.

### Изменено

- Переход от compile-time `NUM_UNITS` к `menu.units_count`.
- `controller define` заменен на `menu.controllers_count`.

## [Август-Сентябрь 2025] - 2025-08-21..2025-09-16

### Добавлено

- Унифицированы структура меню и структура данных для всех контроллеров.
- Реализовано плавное управление сервоприводом.
- Добавлен gain multiplier.
- Реализован новый `Ki` с `tau_aw`.

### Исправлено

- Доведена точность PID примерно до `±1.5°C`.
- Исправлена нестабильность нагрева.
- Скорректирован выход air PID.
- Увеличен `Ki` для уверенного выхода на целевое значение.

### Изменено

- Обновлен менеджер PWM-каналов.

## Примечания

- Коммиты вида `work in progress` и служебные изменения `.DS_Store` в changelog подробно не раскрываются.
- Когда в репозитории появятся оформленные релизы или теги, ранние разделы имеет смысл разбить на точные версии.
